#ifs 
Enables the dispatcher to assign, reassign and monitor the resources for the work tasks via Gantt views or Geolocation based map interfaces. It delivers both 

Dispatchers choose manual resource allocation 
- Balancing workloads
- Addressing scheduling exceptions
- Managing Last Minute Changes 
- SLA Driven Activities
- Using Gantt Chart or Map view 
- Enhanced scheduling and visibility 
- Improved Operational Efficiency 
# Inter-related Scenarios 
- Manual allocation 
- Bucket resource allocation 
- BDR for Dispatch console 
- Manual scheduling with Dispatch Console, Gantt chart
- Manual Scheduling with Dispatch Console, Map (real time location data)
